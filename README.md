# UOOC 2025.11学习助手

> 仓库：https://github.com/imdecimo/UOOC_learning_assistant

## 脚本简介

本脚本专为 UOOC 优课联盟课程平台打造，可实现全自动化学习体验。支持连续播放、自动倍速、自动静音、小节连播、自动跨章节跳转、全自动答题(视频中而非测验)、课程讨论区自动刷评论，并针对答题弹窗做了智能关闭优化，兼容大多数 UOOC 课程结构。

## 功能清单

- 视频自动播放，无需手动点击
- 自动切换到二倍速播放，加快学习效率
- 视频自动静音，学习不打扰别人
- 自动跳转至下一个未完成视频，支持自动展开章节
- 自动答题，智能识别题目并快速提交，仅答一次防死循环
- 答题弹窗自动关闭，避免卡死或影响连播流程
- 支持多轮自动检测，兼容延迟加载章节和视频
- 刷完本章节自动进入下一个章节，直至全部课程完成
- 自动刷课程讨论区评论，自动凑够设定条数（v1.5 新增）

## 安装方法

1. 请确保浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/) 或其他用户脚本扩展。
2. 复制 `UOOC 学习助手_szu_v2-1.5.1.user.js` 全部内容，或点击油叉/Greasy Fork 安装按钮。
3. 保存后，打开 UOOC 优课联盟课程网站学习页面，脚本会自动运行。

## 使用说明

### 刷课

- 页面右侧出现「递归上课：关闭」按钮，点一下变成「开启」即开始自动刷课
- 自动倍速、静音、答题、弹窗关闭等功能全部自动触发
- 连续 3 轮都找不到可刷的视频时，脚本会自动关闭递归，避免空转
- 遇到加载不出来的小节会自动重试 2 次后跳过，不会卡死在单节上

### 刷评论（v1.5 新增）

- 打开任意课程页面（地址形如 `/home/course/课程id`），右侧出现「刷评论：关闭」面板
- 设定目标条数后点按钮开始，脚本会自动拉取讨论区帖子列表，逐帖发表评论
- 评论内容默认复制原帖正文（正文为空则用标题），可勾选「末尾追加随机短评」降低被判重复的概率
- 每条间隔 20~40 秒随机；连续失败 3 次会自动暂停 2 分钟
- 达到目标条数自动停止；目标条数保存在浏览器本地，刷新页面不丢
- 刷完当前列表后会重新拉取列表继续，直到凑够条数

## 参数调整

脚本顶部有 `CONFIG` 配置块，可直接改：

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `speed` | 播放倍速 | `2` |
| `mute` | 是否自动静音 | `true` |
| `videoBootMs` | 点击小节后等待视频加载的时间 | `20000` |
| `videoStallMs` | 播放进度停滞多久判定卡死 | `120000` |
| `maxNodeFailures` | 同一小节失败几次后跳过 | `2` |
| `maxIdleRounds` | 连续几轮刷不到内容就自动关闭递归 | `3` |
| `comment.minGapMs` / `maxGapMs` | 两条评论的随机间隔 | `20000` / `40000` |
| `comment.maxFailures` | 连续失败几次触发冷却 | `3` |
| `comment.cooldownMs` | 冷却时长 | `120000` |
| `comment.maxContentLen` | 单条评论最大长度 | `800` |

## 常见问题 & 注意事项

- 仅支持 UOOC 优课联盟课程平台，其他网站无效
- 脚本自动跳过章节测试题（如需要手动完成请注意）
- 本脚本只可答视频中的弹窗题目，无法自动回答测验题目，测验请手动完成
- 刷评论依赖课程讨论区接口，若平台改版导致接口变化，脚本会在日志区提示失败原因，请反馈
- 若脚本出现无法自动连播、答题、弹窗无法消除等情况，请刷新页面或反馈具体问题

## 调试

浏览器控制台输入 `__UOOC__` 可查看当前配置、日志与刷评论状态，例如：

```js
__UOOC__.logLines          // 最近日志
__UOOC__.commentBot.state  // 刷评论进度
__UOOC__.config.speed = 1.5
```
